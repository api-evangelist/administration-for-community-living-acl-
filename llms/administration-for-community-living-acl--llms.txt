# Administration for Community Living (ACL)

> ACL is an operating division of the US Department of Health and Human Services. It works to maximize the independence, well-being and health of older adults, people with disabilities across the lifespan, and their families and caregivers. ACL administers the Older Americans Act programs, supports disability services through Centers for Independent Living, and publishes program statistics through the AGing, Independence, and Disability (AGID) Program Data Portal.

> Provenance: ACL does not publish an llms.txt. This file was GENERATED by API Evangelist on 2026-08-30 from the apis.yml profile and from artifacts probed in this repository. It is not a provider-published document.

## What ACL publishes for machines

ACL runs no developer program. There is no developer portal, no API reference, no OpenAPI, GraphQL, AsyncAPI, gRPC or WSDL contract, no SDK, no CLI, no MCP server, no A2A agent card, and no /.well-known document on any ACL host. Two live API surfaces exist and both are undocumented internal back ends discovered by reading the public JavaScript of ACL's own web applications.

## Live API surfaces (undocumented)

- [AGID Program Data API](https://sic.acl.gov/p-agid-ui-fn): The back end of the AGID Program Data Portal. Azure API Management gateway in front of Azure Functions. Twelve POST-only RPC operations (GetDataSets, GetYearInfo, GetTableData, GetCategoryType, GetCategorySubType, GetCategoryByDataset, GetCategoryDemoGroups, GetDataElements, GetGeoGroups, GetGeoSubGroups, GetGeoTribes, getGeoGrantees). Requires an Ocp-Apim-Subscription-Key header; ACL publishes no way to obtain one. Read-only.
- [Eldercare Locator Content API](https://ehc.acl.gov/api): Strapi 5 headless CMS backing eldercare.acl.gov. The eldercareglobal collection is readable anonymously; other collections are not granted to the public role. Read-only.

## Data available

Older Americans Act State Program Reports (Title III), American Indian, Alaskan Native and Native Hawaiian Program Performance Reports (Title VI), Title VII elder rights programs, the National Survey of Older Americans Act Participants (NSOAAP), the National Ombudsman Reporting System (NORS), the National Adult Maltreatment Reporting System (NAMRS), Independent Living Services and Centers for Independent Living performance data, I/DD longitudinal data, and American Community Survey special tabulations on aging and disability.

## What an agent should know before calling

- Both surfaces are read-only. There is no write operation, so idempotency and reversibility do not apply.
- No rate limit is published and no rate-limit header is returned. Pace conservatively.
- Errors are not consistent: 400 returns a plain-English sentence, 401 and 404 return Azure API Management JSON, and at least one operation returns a 500 carrying an unhandled stack trace. There are no stable error codes.
- The AGID gateway returns JSON under a text/plain content-type.
- Neither API is supported for third-party use. Bulk CSV and Excel downloads at https://agid.acl.gov/DataFiles/ are the surface ACL actually intends the public to use.
